# 画像グリッドオーバーレイツール

## 概要

このウェブアプリケーションは、お手持ちの画像にカスタマイズ可能なグリッド（格子線）を重ねて表示し、結果を画像ファイルとしてダウンロードできるツールです。

## 主な機能

*   **画像の読み込み:**
    *   画面右上のエリアに画像を**ドラッグ＆ドロップ**するか、エリアをクリックして**ファイルを選択**します。
    *   主要な画像形式に対応しています。

*   **グリッドタイプの選択:**
    *   **スクエア (Square):** 四角形のマス目を生成します。
    *   **ヘクス (Hex):** 六角形のマス目を生成します（ヘクスへの塗りつぶしは現在未対応です）。

*   **グリッド生成モード:**
    *   **マス目サイズ指定:** グリッドの1マスのサイズをピクセル単位で指定します。
    *   **行と列の数指定:** 画像全体をいくつの行と列で分割するかを指定します。

*   **グリッドのカスタマイズ:**
    *   **オフセット:** グリッド全体の描画開始位置をX軸・Y軸方向に調整できます。
    *   **線の太さ:** グリッド線の太さをピクセル単位で設定します。
    *   **線の色:** グリッド線の色を選択します。
    *   **線の透明度:** グリッド線の不透明度をスライダーで調整します。
    *   **線の種類:**
        *   `実線 (Solid)`
        *   `点線 (Dotted)`
        *   `破線 (Dashed)`
        *   `グラデーション線 (Gradient)`: 中心、周辺、外側の3色を指定して放射状のグラデーション線を描画します。
        *   `文字 (Text)`: 指定した文字を格子線のように並べて表示します。フォントサイズ、回転（左右90度）、文字間隔も設定可能です。

*   **インタラクティブなプレビュー:**
    *   設定の変更は右側のプレビューエリアに**リアルタイムで反映**されます。
    *   **ズーム:** プレビューエリア上で**マウスホイール**を回転させると、表示を拡大・縮小できます。ズームはマウスカーソル位置が中心になります。
    *   **パン（移動）:** **Ctrlキーを押しながら左クリックでドラッグ**するか、**マウスの中ボタン（ホイールボタン）**を押しながらドラッグすると、ズームした状態の表示領域を移動できます。

*   **グリッド塗りつぶし (スクエアグリッドのみ):**
    *   左パネルで**2色の塗りつぶし色**と**透明度**を設定できます。
    *   プレビューエリアの**マス目を左クリック**すると、設定した色1 → 色2 → 透明（塗りなし）の順に状態が切り替わります。
    *   **左クリックしたままドラッグ**することで、連続してマス目を塗りつぶせます。
    *   「塗りつぶしリセット」ボタンで、全てのマス目の塗りを解除できます。

*   **ダウンロード:**
    *   **画像+グリッド:** グリッドと塗りつぶしが合成された画像をダウンロードします (webp, jpg, png)。
    *   **グリッドのみ:** 背景画像なしで、グリッド線と塗りつぶしのみをダウンロードします (png, webp は背景透明、jpg は白背景)。

## 使い方

1.  **画像アップロード:** 右上の破線エリアに画像をドラッグ＆ドロップするか、クリックしてファイルを選択します。
2.  **グリッド設定:** 左側のパネルで、グリッドのタイプ、生成モード、線のスタイル、色、オフセットなどを好みに合わせて調整します。
3.  **塗りつぶし (任意):** スクエアグリッドの場合、左パネルで塗りつぶし色を設定し、右のプレビュー上でマス目を左クリックまたはドラッグして色を塗ります。
4.  **プレビュー操作:**
    *   **ズーム:** マウスホイールで行います。
    *   **パン:** Ctrl + 左ドラッグ、または中ドラッグで行います。
    *   **塗りつぶし:** 左クリック / 左ドラッグで行います。
5.  **ダウンロード:** 左パネル下部の「ダウンロード」セクションで、希望の形式（画像+グリッド / グリッドのみ）とファイルフォーマットを選択し、「ダウンロード」ボタンをクリックします。

## 操作のヒント

*   **プレビュー移動:** Ctrl + 左クリックドラッグ or 中ボタンドラッグ
*   **プレビュー拡大縮小:** マウスホイール
*   **マス目の塗りつぶし/変更:** 左クリック or 左クリックドラッグ

# 画像グリッドオーバーレイWebApp

このウェブアプリケーションは、画像上にカスタマイズ可能なグリッドを重ねて表示し、その結果をダウンロードできるツールです。

## 機能

*   **画像のアップロード:**
    *   ドラッグ＆ドロップまたはファイル選択で画像をアップロードできます。
    *   主要な画像形式（JPEG, PNG, WebPなど）に対応。
*   **グリッド設定:**
    *   **グリッドモード:**
        *   マス目サイズ指定（ピクセル単位）
        *   行と列の数指定
    *   **オフセット:** グリッド全体のX軸、Y軸方向の移動量（ピクセル単位）
    *   **線のスタイル:**
        *   線の太さ
        *   線の色
        *   線の種類（実線、点線、破線、グラデーション線、文字）
        *   線の透明度
    *   **文字グリッド設定:** (線の種類で「文字」を選択時)
        *   表示する文字
        *   フォントサイズ
        *   回転方向（左回転、右回転）
        *   文字間隔
    *   **グラデーション線設定:** (線の種類で「グラデーション線」を選択時)
        *   中央の色
        *   周辺の色
        *   外側の色
*   **プレビュー:**
    *   設定変更はリアルタイムでプレビューに反映されます。
    *   プレビューエリアはスクロール可能で、大きな画像でも全体を確認できます。
*   **ダウンロード:**
    *   **画像+グリッド:** グリッドを重ねた画像をダウンロードできます（WebP, JPG, PNG形式）。
    *   **グリッドのみ:** グリッド線のみの画像をダウンロードできます（PNG, WebP, JPG形式、背景透明）。

## 使い方

1. **画像のアップロード:** 画面中央のエリアに画像をドラッグ＆ドロップするか、クリックしてファイルを選択します。
2. **グリッド設定:** 左側のパネルで、グリッドの種類、サイズ、色、オフセットなどを調整します。
3. **プレビュー:** 右側のパネルで、設定したグリッドが画像にどのように重なっているかを確認します。
4. **ダウンロード:**
    *   「ダウンロード」セクションで、希望する形式のボタンをクリックして画像をダウンロードします。
    *   「画像+グリッド」または「グリッドのみ」を選択できます。
